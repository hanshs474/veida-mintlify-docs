[Veida](https://veida.ai/?utm_source=mintlify&utm_medium=docs) is an online AI image generator.
Its anonymous free tier answers plain HTTP calls without a key, an account or a card, and these
docs cover the clients that wrap it in thirteen languages.

```python
from veida import generate
print(generate("a paper boat on a calm lake at sunrise, soft light", aspect_ratio="16:9"))
```

Every client does the same three things:

1. invents a fresh client id (sent as `x-anon-id`), because the free grant pays for one image per id;
2. submits the prompt to `POST /api/ai/generate`;
3. polls `GET /api/ai/anon-query` until a CDN URL comes back, and returns it.
